VeloRent · Guía de estilo (Fase 5)

Estilo visual del proyecto

Tema “VeloRent — oscuro de lujo”: fondo casi negro, acentos dorados, texto claro y títulos con tipografía serif elegante. Esta página es la referencia para todo el equipo.

Regla de equipo: todas las pantallas usan solo las clases y los tokens (variables) de estilos.css. No se escriben colores a mano en el HTML. Si falta un estilo, se agrega al CSS y se avisa en el PR.

1. Colores (tokens)

Se usan como var(--nombre) en el CSS. No usar códigos hex sueltos.

Fondo--color-fondo · #0f0f12
Superficie--color-superficie · #1a1a1f
Superficie 2 (campos)--color-superficie-2 · #141418
Dorado (acento)--color-primario · #c9a24e
Dorado oscuro (hover)--color-primario-oscuro · #b1883a
Texto--color-texto · #f3f1ec
Texto suave--color-texto-suave · #a5a39c
Peligro / error--color-peligro · #e5736a
Éxito--color-exito · #5fb97e
Aviso--color-aviso · #d9a441

2. Tipografía

Título con serif (Playfair Display)

Subtítulo con serif

Texto de párrafo con la tipografía del sistema (sans-serif). Legible y neutra para formularios y tablas. Un enlace se ve dorado.

Títulos: --fuente-titulo (serif). Texto: --fuente-texto (sans).

3. Botones

Principal (dorado) Secundario (fantasma) Peligro

Clases: .boton, .boton.secundario, .boton.peligro. El principal es la acción destacada de la pantalla (una sola por pantalla).

4. Campos de formulario

Completá este campo.

El asterisk dorado marca obligatorio. El error usa .campo.error + .mensaje-error (ver validacion.js).

5. Etiquetas de estado

Disponible Confirmada Pendiente Mantenimiento Retirado Cancelada

Clases: .estado.ok (verde), .estado.espera (ámbar), .estado.baja (gris, para lo dado de baja).

6. Avisos

Aviso informativo (dorado).
Operación realizada con éxito.
Atención: revisá este dato.
No se pudo completar la acción.

Clases: .aviso, .aviso.exito, .aviso.advertencia, .aviso.error.

7. Cómo armar una pantalla nueva

Partí de plantilla.html (back-office) o plantilla-publica.html (formulario público). Enlazá siempre estilos.css y, si tiene formulario con validación, validacion.js. Usá solo las clases de esta guía.
