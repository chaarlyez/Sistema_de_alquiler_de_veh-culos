# Fase 5 — Fuentes editables de los diagramas de navegación

Esta carpeta contiene el **archivo fuente editable** (`.mmd`, sintaxis
[Mermaid](https://mermaid.js.org/)) de cada diagrama de navegación de la Fase 5. Mismo criterio
que las fuentes de la Fase 3 (`docs/03-uml/fuentes/README.md`): se editan en
[Mermaid Live Editor](https://mermaid.live) o con una extensión de VS Code, y la fuente y el bloque
embebido en el `.md` de la parte tienen que tener siempre el mismo contenido (se cambian juntos,
en el mismo commit).

Cada integrante completa solo la tabla de su parte.
